# NOBU11PK 천하창세 PK 한국어 패치 설치 및 사용 설명서

## 대상

- 신장의 야망 11 PK / 천하창세 PK
- 한국어 패치 배포 기준: **v1.0.19**

## 설치

1. Steam에서 게임이 정상 설치되어 있는지 확인합니다.
2. 한국어 패치 배포 ZIP을 원하는 폴더에 압축 해제합니다.
3. 배포 폴더의 파일 구조를 임의로 변경하지 않는 것을 권장합니다.
4. `NOBU11PK_KoreanPatch.exe`를 실행합니다.
5. 런처에서 **한글판 실행**을 선택합니다.

## 실행 방식

런타임 문자열 패치가 필요한 항목까지 한국어로 적용하려면 반드시 한국어 패치 런처의 **한글판 실행**을 사용합니다.

Steam 라이브러리에서 게임을 직접 실행하면 정적 GRP/MSG 변경은 보일 수 있지만, 런타임 메모리 패치 항목은 적용되지 않을 수 있습니다.

## 배포 파일

최종 USB 배포 검증에서 다음 실행/패치 구성의 동작이 확인되었습니다.

- `NOBU11PK_KoreanPatch.exe`
- `NOBU11PK_KR.exe`
- `patch/data.pack`
- `patch/patch_manifest.json`
- `patch_data.json`
- `launcher_data/metadata/ORIGINAL_HASH_CATALOG.json`
- `launcher_config.json`

최종 배포 패키지에는 README와 SHA256SUMS도 포함됩니다.

## Steam 무결성 검사 주의

Steam의 다음 기능은 패치된 LIVE 게임 파일을 일본어 원본으로 복구할 수 있습니다.

- 게임 파일 무결성 검사
- 설치 파일 확인/복구
- Steam이 설치 파일을 다시 취득하는 작업

실제 프로젝트 검증에서는 패치 대상 107개 파일이 모두 원본 상태로 복구되는 현상이 확인되었습니다.

무결성 검사를 실행했다면 다음 순서로 복구하십시오.

1. 게임과 한국어 패치 런처를 종료합니다.
2. 최신 검증 패키지를 다시 설치합니다.
3. 패키지와 게임 설치 폴더의 패치 대상 파일이 정상 동기화되었는지 확인합니다.
4. 한국어 패치 런처로 게임을 실행합니다.
5. 시작 메뉴와 주요 UI가 다시 한국어로 표시되는지 확인합니다.

## 런타임 검증 기준

다음과 같은 항목은 한국어 패치 런처 경유 실행을 기준으로 확인합니다.

- EXE 런타임 문자열 패치
- `patch_data.json` 기반 문자열
- 한글 직접입력/IME 관련 기능
- 런처가 메모리에 주입하는 기능

반면 GRP/MSG 등 정적 파일 변경은 Steam 직접 실행에서도 보일 수 있습니다.

## 문제 발생 시

### 게임이 일본어로 돌아간 경우

Steam 무결성 검사 또는 설치 파일 복구를 최근 수행했는지 확인한 뒤 최신 한국어 패키지를 다시 설치하십시오.

### 일부 문자열만 일본어로 보이는 경우

`NOBU11PK_KoreanPatch.exe`에서 **한글판 실행**으로 시작했는지 확인하십시오. 런타임 패치 대상 문자열은 일반 Steam 실행에서는 적용되지 않을 수 있습니다.

### 화면에서 글자가 잘리거나 겹치는 경우

문제가 발생한 화면명과 위치를 스크린샷으로 기록하면 MSG/GRP/EXE/FONT 출처를 다시 검증할 수 있습니다.

## 원본 게임 파일

이 한국어 패치 배포는 원본 게임 자체를 재배포하기 위한 것이 아닙니다. 게임은 정식 설치본이 필요합니다.

프로젝트에서는 원본 게임 설치 기준을 PRISTINE으로 보존하며, 확인되지 않은 상태에서 원본을 직접 덮어쓰지 않는 것을 원칙으로 합니다.
