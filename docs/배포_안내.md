- USB 최종 배포 패키지 정리: PASS

## 배포 원칙

- 원본 게임 자체는 배포하지 않습니다.
- 배포물에는 패치 실행에 필요한 파일과 설명서만 포함합니다.
- 개발 작업대, SSOT, Evidence, 백업, 임시파일, 디버그 파일은 최종 배포물에서 제외합니다.
- 정식 게임 설치본이 필요합니다.

## 설치 후 실행

런타임 패치가 필요한 항목까지 적용하려면 `NOBU11PK_KoreanPatch.exe`의 **한글판 실행**을 사용하십시오.

## Steam 무결성 검사 주의

Steam의 게임 파일 무결성 검사/설치 파일 확인·복구는 한국어 패치가 적용된 게임 파일을 일본어 원본으로 되돌릴 수 있습니다.

실제 검증에서는 패치 대상 107개 파일이 전부 원본 상태로 복구된 사례가 확인되었습니다. 해당 기능을 실행했다면 최신 한국어 패치를 다시 설치하고 런타임을 재검증하십시오.
